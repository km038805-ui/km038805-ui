# MS Excel Data Cleaning Portfolio Sample

By Muhammad K. — portfolio practice project with simulated sample data. This is not client work.

## Cleaning steps shown
- Trimmed extra spaces and fixed name capitalisation
- Standardised city names and date format (YYYY-MM-DD)
- Removed 1 duplicate order row
- Removed 1 row with missing customer name
- Converted prices to numbers and added line totals

## Result
6 messy rows became 4 clean rows. Total sales in the clean sample: 124 SAR.

- `excel_data_cleaning_sample.xlsx` — Before, After and Summary sheets

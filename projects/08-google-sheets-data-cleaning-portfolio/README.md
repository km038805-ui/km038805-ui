# Google Sheets Data Cleaning Portfolio Sample

By Muhammad K. — portfolio practice project with simulated sample data. This is not client work.

## What this shows
- Cleaning a messy contact list in Google Sheets style
- Trimming spaces, fixing capitalisation, lowercasing emails
- Removing duplicate contacts and flagging an invalid email for checking

## Formulas used
TRIM, PROPER, LOWER, UNIQUE, and an email check with SEARCH.

## Files
- `google_sheets_cleaning_sample.xlsx` — opens in Google Sheets, includes Clean Contacts and Formulas Used sheets
- `contacts_messy.csv` and `contacts_cleaned.csv`

## Tools
Google Sheets
